# 资产工作台（asset-workbench）

角色资产产出系统。一套上游资产源，三条产出线，一条 Agent 执行链路。

## 组成

| 层 | 内容 |
|---|---|
| 上游资产 | 概念图 → 定妆图 → 部件语义拆分 → 动作语义字典 |
| 产出线 | 皮套 / 像素 / 萌化动画化 |
| 执行链路 | 环节流水线 + Agent 通道 + 人工审核门 |
| 数据契约 | 图像 / 项目 / 发布 / 驱动（四层） |
| 择优机制 | 路由键 + 策略 + 回退链 |
| Agent 承载 | 预设包（六组件声明）+ 内核工作循环 |
| 模型路由 | 内容类型 → 底模族 → 模型 → LoRA |

## 上游链

概念图 → 定妆图 → 部件语义拆分 → 动作语义字典

分叉点：定妆图。分叉后各产出线独立执行。

## 产出线

| 线 | 出口 | 落档 |
|---|---|---|
| 皮套 | Live2D 模型包（.model3 / .moc3 / .physics3 / .motion3） | 规格 v0.3 |
| 像素 | 像素游戏素材（sprite / 图集） | 走查 v0.1 |
| 萌化动画化 | 萌化图 / 循环动画（GIF / sprite sheet / JSON） | 工具调研完成 |

## 皮套线（E 线）

环节链：E0 输入 → E1 定妆 → E2 拆层 → E3 补修 → E4 入编辑器 → E5 绑参 → E6 物理动作 → E7 导出 → E8 验收

每环节五要素：具体操作 / 内部逻辑 / 产出契约 / 通道 / 人工审核门。

Agent 通道四类：软件 API / MCP / CLI·本地推理 / GUI 自动化。

## 数据契约（四层）

| 契约 | 格式 | 连接 |
|---|---|---|
| 图像契约 | PNG-alpha / PSD 层结构 | 文生图 ↔ See-Through ↔ PS |
| 项目契约 | .cmo3 + 参数 CSV | 编辑器 ↔ 外部 API ↔ CSV 导入 ↔ MCP |
| 发布契约 | .model3 / .moc3 / .physics3 / .motion3 | 模型包 ↔ VTS ↔ 游戏引擎 |
| 驱动契约 | PARAM 映射表 | OpenSeeFace ↔ VTS ↔ 模型 |

工具吃吐同一契约即可替换。

## 路由规则

路由键：输入特征 / 质量要求 / 成本 / 隐私 / 环境 / 工具健康度。

策略：规则路由 → 评分路由 → 实测路由。起步用规则 + 回退链。

回退链：主选失败 → 备选 → 人工兜底。

## 预设包（Agent 承载）

六组件：preset.yaml / rules.md / pipeline.json / contracts.md / assets.md / memory.md。

内核工作循环：

```
接收指令 → 识别预设 → 载入(规则/契约/资产) → 需求规格化
→ 逐环节(分派 → 调工具 → 产出 → 呈现 + 审核门)
→ 全部通过 → 写记忆 → 交付总结
返工：用户指明环节 → 回该环节重跑
```

## 模型能力地图（E1）

内容类型 → 底模族 → 具体模型 → LoRA。

规律：底模决定能画什么，LoRA 决定是什么画风；Pony 与 Illustrious/NoobAI 生态不互通。

调优四件套：模型资产登记 / 选型路由 / 抽卡协议 / 反馈闭环。
