三条业务线

每线 = 环节流水线 + 四类 Agent 通道 + 人工审核门；四层数据契约连接工具。

E 线皮套

  • 出口：Live2D 模型包（.model3 / .moc3 / .physics3 / .motion3）
  • 环节：E0 输入 → E1 定妆 → E2 拆层 → E3 补修 → E4 入编辑器 → E5 绑参 → E6 物理动作 → E7 导出 → E8 验收
  • 通道：Cubism 外部集成 API + 参数 CSV（主），Blender 3D 建模 / VRM 出口（已验证）
规格 v0.3 落档

P 线像素

  • 出口：像素游戏素材（sprite / 图集）
  • 双轨：人类像素画师 × AI 工作台
  • 风险：帧一致性 / 调色板锁定 / 尺寸网格 / 循环闭合 / 图集格式 / 商用许可
  • 通道：Aseprite CLI / 社区 MCP 候选，Blender 摆 pose 预渲染候选
走查 v0.1 落档

M 线萌化动画化

  • 出口：萌化图 / 循环动画（GIF / sprite sheet / JSON）
  • 手绘：Animated Drawings → Dreamina Sketch-to-Video → ToonCrafter
  • 像素：Sprite-AI → Ludo Forge Pixel / Anijam
  • 接入通道待定（API 优先，GUI 自动化兜底）
