04路由机制

候选工具池按路由键择优；每单记录回流为工具健康度。

路由键

  • 输入特征
  • 质量要求
  • 成本约束
  • 隐私合规
  • 环境（显卡 / 版本）
  • 工具健康度

策略顺序

  • 规则路由（硬约束 if-then）
  • 评分路由（权重打分）
  • 实测路由（小样本试跑）

回退链

  • 主选工具
  • 备选工具
  • 最后兜底：人工

07设计原则

  • PR-01工作台只声明与展示，不承载业务逻辑；复杂逻辑在 Agent 内部小循环
  • PR-02原件是唯一真相
  • PR-03契约先行，声明使用纯 JSON / YAML
  • PR-04翻译不了的不提前设计
  • PR-05每环节人工审核门，产出不合格不进下一步
  • PR-06半自动编排，Agent 保证成品格式与可加载，质量验收归人
