# 软件接入 Skill 生成规范 v0.1

半开放软件接入机制。任何具备可编程面的工程软件，均可按本规范生成接入 Skill（软件操作手册）；生成物通过通路验证后登记，供路由主动选择；满足同一能力接口的软件可随时替换。

## 1. 接入门槛

软件具备以下任一可编程面即入选：

- MCP server：存在 `.mcp.json` / 官方 MCP 文档，或社区可用 server
- CLI：可执行文件，支持 `--help` / 子命令
- 本地服务：监听 socket / HTTP 端口，具备 JSON 或等价协议
- 官方 SDK / Python API / 脚本语言（Lua / ExtendScript 等）

检测清单：查 MCP 配置 → 查 CLI → 查端口 → 查 SDK 文档；任一命中即通过门槛。

## 2. 生成流程（四步）

### 2.1 探测

定位可编程面，运行最小探针：

1. 心跳：`ping` / 等价存活检查
2. 读状态：场景 / 文档 / 项目信息
3. 执行一次：运行最小操作
4. 回传：截图 / 输出 / 结果文件

探针全部返回成功，进入映射；失败则记录失败点，不进入生成。

### 2.2 映射

将探测到的能力映射到能力接口清单：

| 能力接口 | 覆盖操作 |
|---|---|
| 3D 建模 | 对象创建 / 修改 / 拓扑 / UV |
| 绑定 | 骨骼 / 权重 / 约束 |
| 导出 | FBX / GLB / VRM / USD / 图集 |
| 拆层 | 图层拆分 / 命名 / 分组 |
| 绑参 | 参数读写 / 映射表 |
| 像素帧 | 画布 / 图层 / 帧动画 |
| 渲染回传 | 视口 / 预览截图 |

软件能力不在清单内的，登记为扩展接口，不强行归类。

### 2.3 生成

产出 SKILL.md，遵守渐进披露（正文 ≤500 行，细节进 `references/`）：

- frontmatter：`name` + `description`（触发条件写入 description，正文不重复）
- 正文章节：角色定位 / 触发场景 / 核心流程 / 约束（MUST / MUST NOT）/ 参考指引
- 附 `scripts/`（确定性探针与操作脚本）、`references/`（协议、清单、模板）、`assets/`（输出模板）

### 2.4 验证

最小通路验证：心跳 + 读状态 + 执行 + 回传，全部通过方可登记。验证脚本与结果留档。

## 3. 登记与可插拔

- 验证通过的生成物登记进路由表：能力接口 × 软件实现 × 通道类型 × 验证记录
- 同一接口允许多实现并列；路由按通道健康度择优，失败自动回退下一实现
- 软件可随时替换：新实现通过验证后登记，旧实现保留或移除，不改变上层流程

## 4. 模板资产

- SKILL.md 模板：见 `connector-skill-builder` Skill 的 `references/skill-schema.md`
- 探针脚本模板：见 `connector-skill-builder` Skill 的 `scripts/probe_template.py`
- 验证协议：见 `connector-skill-builder` Skill 的 `references/verification.md`
