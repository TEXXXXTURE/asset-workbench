# 最小通路验证协议

> Reference for: connector-skill-builder
> Load when: 验证步骤

## 验证四项

| 序 | 验证 | 判定 |
|---|---|---|
| 1 | 心跳 | ping / 存活响应成功 |
| 2 | 读状态 | 场景 / 文档 / 项目信息返回 |
| 3 | 执行 | 最小操作无报错 |
| 4 | 回传 | 截图 / 输出 / 结果文件落盘 |

四项全过 → 通过；任一失败 → 不通过，记录失败点。

## 执行要点

- 验证脚本独立于手册，先于手册编写完成
- 探针超时按通道调整（socket 默认 10s）
- 失败重试上限两次；同错再现即停止，记录成因

## 留档与登记

- 验证记录：日期 / 软件 / 通道 / 四项结果 / 探针脚本路径
- 登记格式：`能力接口 × 软件 × 通道类型 × 验证记录`
- 通过后才可写入路由表
